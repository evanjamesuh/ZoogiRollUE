# Zoogi Roll

A browser marble battler. One Node server serves the page and the API. A match is played in the browser. Accounts, leaderboards, chat, and saved creations use local Postgres.

## What you need

- Node.js 20 or newer
- Docker Desktop, for Postgres

These commands are for Windows PowerShell. On macOS or Linux, use `cp .env.example .env` instead of `Copy-Item`.

## First-time setup

1. Copy the game art from the Replit project into `client/public`. This snapshot does not include those files. You want the `models`, `sounds`, `videos`, and `textures` folders, plus `main-bg-video.mp4` at the root of `client/public`. The menu loads without them. A grass-map match needs `models/floating_island_stage.glb` or the arena cannot draw that stage. Do not commit those binaries unless you have decided to store them in git.

2. In PowerShell, from the project folder:

```powershell
Copy-Item .env.example .env -Force
docker compose up -d
npm install
npm run db:push
npm run dev
```

3. Open http://127.0.0.1:5000

`npm run dev` loads `.env` before the server reads any settings. That works the same on Windows and Mac. Postgres from Compose listens only on `127.0.0.1:5432`. The default login in `.env.example` matches `docker-compose.yml` (`zoogi` / `zoogi`, database `zoogiroll`). Change both files together if this machine is shared.

## Day to day

```sh
docker compose up -d
npm run dev
```

Stop the database with `docker compose stop`. The page still starts if Postgres is down or `DATABASE_URL` is missing. Sign-in, scores, and other saved data then return a clear error instead of saving.

## Play on a phone over home Wi-Fi

`npm run dev` stays on this PC only (`127.0.0.1`). To let a phone on the same Wi-Fi open the game, from the project folder:

```powershell
npm run dev:lan
```

That works in Windows PowerShell and Command Prompt. On startup the server prints a line like `Phone on this Wi-Fi: http://192.168.1.23:5000`. Type that address into the phone's browser. Windows may ask to allow Node.js on private networks; allow it.

`npm run dev:lan` sets `HOST=0.0.0.0` for that process, which wins over `HOST` in `.env`. The default without that script is still localhost. You can also set `HOST=0.0.0.0` in `.env` and run `npm run dev`.

Live reload uses the same host and port as the page, so the phone's websocket reaches this PC instead of `localhost`.

After `npm run build`, `npm run start:lan` serves the built game on the LAN the same way. `npm start` stays on localhost.

## Check the built app

```sh
npm run build
npm start
```

`npm start` serves the built files on `$PORT` (5000 if unset). The account login cookie is marked secure in that mode, so signing in over plain `http://127.0.0.1` will not stick. Use `npm run dev` for normal play on your machine. The game itself does not need Postgres.

## Put it on the internet (Render)

`render.yaml` is a free Render web service. It builds with `npm install && npm run build` and starts with `npm start`. The service listens on `0.0.0.0` and Render's `PORT`. No database is required.

1. Push this repo to GitHub.
2. In Render, choose New → Blueprint and point it at the repo. Render reads `render.yaml`.
3. Leave `DATABASE_URL` unset. Accounts, leaderboards, and saved creations stay off, and a match still runs in the browser.
4. Optional: in the Render dashboard, add `PLAY_PASSWORD` to a value only you know. Do not put that value in git. When it is set, the site shows a password page before the game. When it is unset, the game is public.
5. Open the `onrender.com` URL Render gives you.

`SESSION_SECRET` is generated by Render. Do not commit a real secret.

## iPhone app

The game can be packed into an iPhone app for TestFlight. Single-player is inside the app. Online features use a server address when you set one. The steps, the Apple Developer Program ($99 a year), and the server address are in [docs/IOS_APP.md](docs/IOS_APP.md). `npm run dev` on this PC is unchanged.

## Optional Meshy key

Create Zoogi and Create Arena call Meshy. Put a key in `MESHY_API_KEY` inside `.env` when you want that. Leave it blank to play without it. The shop does not take payment.

## Useful commands

| Command | What it does |
| --- | --- |
| `npm run dev` | Game and API with live reload, this PC only |
| `npm run dev:lan` | Same, but phones on your Wi-Fi can open it |
| `npm test` | Headless check of launch, collision, scoring, and hosting |
| `npm run check` | Typecheck |
| `npm run build` | Production bundle in `dist/` |
| `npm start` | Serve the production bundle on this PC |
| `npm run start:lan` | Serve the production bundle on your Wi-Fi |
| `npm run db:push` | Create or update tables in local Postgres |
| `npm run build:ios` | Pack the iPhone app. See [docs/IOS_APP.md](docs/IOS_APP.md) |
| `npm run cap:sync` | Copy the app id and web bundle into the Xcode project |

More about how the game is put together is in [docs/design-notes.md](docs/design-notes.md).
