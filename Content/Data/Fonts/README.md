# Menu fonts

- `Cinzel-Black.ttf`, `Cinzel-Bold.ttf`: Cinzel by Natanael Gama, latin subset (weights 900 / 700),
  downloaded Oct 19 2026 from fontsource (`cdn.jsdelivr.net/fontsource/fonts/cinzel@latest/latin-{900,700}-normal.ttf`).
- License: SIL Open Font License 1.1, https://openfontlicense.org (Google Fonts: https://fonts.google.com/specimen/Cinzel).
- Used by the Clash front-end menus (`ZoogiMenuClashStyle.h`, `ZCComposite`); Roboto Black is the fallback if these are missing.
