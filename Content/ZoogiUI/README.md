# Zoogi Roll Arena UI

All the game's UI screens, matched to the reference art: the Title screen, Deck, Arena Selection, Story Episodes, Shop, Settings, a Loading screen for each of the 8 arenas, the 4-player Board Battle, and the Battle HUD.

## Open it on your PC
1. Download this folder (on GitHub: **Code → Download ZIP**, or `git clone` and switch to the `zoogi-ui-screens` branch).
2. Open `zoogi-ui/index.html` in Chrome or Edge. No install needed.
3. Add `#dev` to the address to get a screen switcher (or press keys 1–9).

## What's inside
- `index.html`, `styles.css`, `script.js`: the whole UI
- `assets/`: all art, icons, backgrounds and fonts
- `unreal/HANDOFF.md`: how to put it into Unreal (WebBrowser bridge or native UMG)
- `unreal/layout.json`: every element's position on the 941×1672 canvas
